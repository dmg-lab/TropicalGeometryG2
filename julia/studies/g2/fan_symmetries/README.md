# Fan symmetries

`analyze_dihedral_action.jl` checks in exact rational arithmetic that the
order-12 taxon symmetry of the coarsest `Trop(G2/P2)` fan is the dihedral
group D12, generated by `(1 5 3 4 2 6)` and `(2 3)(5 6)`, and that it acts by
automorphisms of the fan that preserve its lineality space. It writes
[`projected_rays.csv`](projected_rays.csv).

Run

```sh
julia --project=julia julia/studies/g2/fan_symmetries/analyze_dihedral_action.jl
```
