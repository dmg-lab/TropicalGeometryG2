# G2-Grassmannian, first characteristic checks (2026-10-01)

Scripts in this folder (Oscar 1.9.0-DEV, dev depot; see ../../README.md for the
command line).  Weights are in the MAX convention of main.tex / Bernd's note;
`in_trop` negates them and uses the min-convention Bayer test.

The ideal is the one of main.tex: 7 linear forms (7linear) + 35 Plücker quadrics,
same integral generators over every field.  NOTE: `g2lib.jl` writes the linear
forms with the signs of main.tex (p13 - p57, ...), while
`julia/studies/g2/ideals/G2GrassmannianIdeal.jl` uses -p13 + p57 etc.; these
generate the same ideal.

witness = 2 p17 p27 p37 + p36 p47 p56 - p14 p45 p67 - p26 p45 p57 - p35 p46 p67
T = Mathieu's tree, a=1,b=1,c=2,d=2, x=(1,0,0,1,0,0,2), via `treemetric` (Bernd's
parametrization).

Primality of the ideal over GF2, GF3 was NOT checked (only dim and degree).

## g2tet.jl

- The six linear G2-conditions on Bernd's tree parametrization (a,b,c,d,x1..x7)
  have rank 4; the tie x2+x5 = x3+x6 is IMPLIED by them (rank stays 4).  Only the
  inequality x2+x5+c+d >= x1+x4 remains of the tropical trinomial condition.
- Solution space: dimension 7 = 4 (cone over the tetrahedron) + 3 (lineality).
- On a basis of the solution space the five term weights (T1 = p17p27p37 term,
  T2..T5 the others, in the order of the witness) are
  ```
  [2, 0, 2, 2, 2]
  [0, 0, 0, 2, -2]
  [0, 0, -2, 2, 0]
  [0, 0, 2, 0, 0]
  [0, 0, 2, 0, 0]
  [0, 0, 0, 2, 0]
  [6, 6, 4, 2, 6]
  ```
  so T3-T2, T4-T2, T5-T2 are three independent linear functions.
- 61 random integral points with a,b,c,d > 0 and x2+x5+c+d >= x1+x4, plus T,
  tested over QQ, GF3, GF2.  In all of them T1 was the strict maximum of the five
  term weights.  Hypotheses and mismatches:
  - H0 (QQ, GF3): in trop  iff  max of all five term weights attained twice  -> 0 mismatches
    (here: never in trop)
  - H2 (GF2): in trop  iff  max of T2..T5 attained at least twice            -> 0 mismatches
    (T and at least 7 of the sampled points were in trop over GF2; only the
    last 30 output lines were inspected, so the exact count is unknown)

The random sample used `rand(-6:6, 7)` combinations of the kernel basis; it was not
seeded, so the exact points are only in the transcript, not reproducible.
